FOMAXO WEBSITE — HOSTINGER + STRIPE SETUP
==========================================

FILES IN THIS PACKAGE
  index.html          the website
  assets/img/         product photos
  checkout.php        creates the Stripe payment page (prices checked here)
  stripe-config.example.php  template for your Stripe key file (see step 3)
  .htaccess           forces https://, protects the key file, speeds up photos

1) HOSTINGER — UPLOAD
   hPanel → Websites → Manage → File Manager → public_html
   (Back up first if WordPress is there: hPanel → Backups.)
   Upload the zip → right-click → Extract. All files must sit directly in public_html.
   Tip: test first inside a folder, e.g. public_html/new  → visit fomaxo.com/new

2) HOSTINGER — HTTPS (padlock)
   hPanel → Security → SSL → make sure SSL is ACTIVE for fomaxo.com.
   The .htaccess file then sends every visitor to https:// automatically.
   (.htaccess is a hidden file — in File Manager turn on "Show hidden files" to see it.)

3) STRIPE — KEYS
   dashboard.stripe.com → Developers → API keys
   Copy the SECRET key (sk_test_... first).
   In File Manager go ONE LEVEL ABOVE public_html (domains/fomaxo.com/), create a new file
   named stripe-config.php, copy in the contents of stripe-config.example.php,
   paste the key between the quotes → Save. (Outside public_html = private, and
   never overwritten when the site updates from GitHub.)

4) TEST (no real money)
   Open the site → add a product → bag → "Pay securely by card".
   Use Stripe test card 4242 4242 4242 4242, any future date, any CVC.
   You should land on the Thank you page, and see the payment in Stripe (Test mode).

5) GO LIVE
   Finish Stripe account verification, then replace the key with sk_live_...
   Real orders: Stripe Dashboard → Payments (shows items, Discovery Set picks,
   customer name, phone and UAE delivery address).
   Turn on email alerts: Stripe → Settings → Notifications → Successful payments.

CHANGING PRICES LATER
   Prices exist in TWO places — change both:
   - index.html  (search for:  prices: { )
   - checkout.php (the $CATALOG list near the top)
   If they differ, the card payment uses checkout.php's price.

TURN CARD PAYMENTS OFF
   In index.html search  stripe: "checkout.php"  and change it to  stripe: ""

CASH ON DELIVERY ORDERS
   Cash on delivery orders (AED 200 minimum, AED 10 fee) are saved by checkout.php in
   domains/fomaxo.com/fomaxo-orders/cash-on-delivery-orders.csv  (one level above
   public_html, private) and emailed to fomaxoasset@gmail.com. To send them to another
   address, add  'orders_email' => 'you@example.com',  to stripe-config.php.
   Minimum order for card and WhatsApp is AED 30. All minimums count the total after
   the multi-buy discount. Change them in BOTH index.html (MIN_ORDER, COD_MIN, COD_FEE)
   and checkout.php ($MIN_ORDER, $COD_MIN, $COD_FEE).
